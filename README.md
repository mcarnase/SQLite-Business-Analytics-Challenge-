SQLite-Business-Analytics-Challenge-

This project uses SQL queries to analyze a sample business database. It answers questions about customers, revenue, employees, and loyalty using joins, aggregations, subqueries, and CTEs.

- SQL (SQLite)
- VS Code
- SQLTools Extension


1. Open the database file in VS Code
2. Open the .sql file  
3. Run queries using 'run on active connection' button 

I learned 
 - How to join multiple tables to get meaningful data  
 - How to use SUM, COUNT, and AVG to analyze data  
 - How to write subqueries to compare values  
 - How to use CTEs to make queries easier to read 
 - How to break down business questions into SQL queries
